# Kanban Task Manager

A drag-and-drop kanban note task manager built with React + Express.

## Setup

```bash
# Backend
cd backend
npm install
npm start

# Frontend
cd frontend
npm install
npm run dev
```

Backend runs on `http://localhost:3001`, frontend on `http://localhost:5173`.

## Usage

- Type a note and press **Add** to create it
- **Drag** notes between To Do and Done columns
- Use the action buttons to mark done, reopen, or delete notes

## Built with

- React 18, Vite
- Express
- Lucide icons
